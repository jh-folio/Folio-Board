# Folio Board 0.6.0

Folio Board 0.6.0은 내 투자 판단을 최신 자료로 다시 검증하는 흐름과, AI 실행을 Agent CLI로 통일한 변경을 담은 릴리즈입니다.

## 주요 변경

- **투자 판단과 검증 이력:** Watchlist의 Thesis·체크포인트와 Portfolio 투자 리뷰에서 내 생각, 현재 사실, 반대 근거, 다음 확인 사항을 함께 살펴볼 수 있습니다. 검토 완료와 구조화 변경은 사용자의 명시적 동작으로 저장합니다.
- **AI 실행을 Agent CLI로 통일:** 작업별 엔진·모델·노력 단계·웹 검색 설정을 같은 실행에 전달합니다. 이전 직접 LLM API 설정은 명시적으로 전환하며, 과거 보고서와 실행 기록은 계속 읽을 수 있습니다. 규칙 기반 대체가 가능한 기능은 AI 없이 사용할 수 있습니다. 모델 목록에 GPT-6 Sol·Luna와 Claude Opus 5.5를 추가했고 이전 모델도 그대로 고를 수 있습니다. 새 모델은 최신 Codex·Claude Code가 필요하므로, 목록에서 고른 모델이 실행되지 않으면 CLI를 먼저 업데이트하세요.
- **기업분석 보완:** 회사 특성에 맞는 분석 쟁점을 기존 보고서 구성에 연결합니다. 부분 출력과 저장 실패는 완료된 보고서로 처리하지 않고 복구 후보로 남기며, 이전 정상 보고서를 보호합니다.
- **딥 리서치 개선:** 주제에 맞는 서술과 자료 연결을 강화하고, 취소·부분 출력·재개 시 입력 변경을 확인합니다. 검증되지 않은 후보를 정상 완료로 복구하지 않습니다.
- **본문 인용과 내보내기:** 출처 원장과 연결되는 인용을 본문 링크로 표시하고 Obsidian·Notion 내보내기에 유지합니다. 위치나 출처가 불명확한 인용은 추정해서 붙이지 않습니다. 과거 저장 보고서는 자동 재작성하지 않습니다.
- **Agent Dock·작업 진단:** 실행 단계와 실패 상태를 더 명확하게 보여주며, 대화별 선택과 작업 설정을 구분합니다. 대화가 투자 판단이나 보고서 근거를 자동으로 바꾸지 않습니다.
- **차트와 읽기 경험:** 공통 차트 테마와 텍스트 대체, 히트맵 라벨·색상·기간 표시를 개선하고 차트 라이브러리를 로컬 번들로 제공합니다. 표시명을 Folio Board로 통일하면서 기존 데이터·설정의 읽기 호환을 유지합니다.

## 업데이트 안내

1. 실행 중인 이전 버전을 종료하고 기존 자료를 백업합니다.
2. 새 ZIP을 별도 폴더에 풉니다. 기존 폴더 위에 덮어씌우지 않습니다.
3. 설정의 자료 위치를 사용 중이면 같은 위치가 연결되는지 확인합니다. 앱 폴더에 자료를 보관한다면 기존 `data/`, `research-inbox/`, `config/`, `.env`를 [설치 안내](../installation.md#updating-to-a-new-version)에 따라 옮깁니다.
4. AI 사용자는 설정에서 지원 Agent CLI 연결과 작업별 설정을 확인합니다. 이전 직접 LLM API 실행은 지원하지 않습니다.
5. 기존 보고서와 투자 노트가 열리는지 확인한 뒤 이전 설치본을 정리합니다.

## 범위와 제한

- 실제 제공자 CLI 세션 이어쓰기, 추가 딥 리서치 비교 실험, Dock 응답 스트리밍은 후속 보류입니다. 기존 작업·후보 복구와 완료된 대화 표시 기능은 유지됩니다.
- 모델별 실제 생성 품질과 외부 계정 연결은 로컬 자동 테스트와 별도로 확인해야 합니다. 자료가 부족하거나 공급자가 값을 반환하지 않으면 미확인 상태를 유지합니다.
- 패키지는 개인 자료와 자격 증명을 포함하지 않습니다. Folio Board는 로컬 사용을 전제로 하며 인터넷에 직접 노출하지 마세요.
