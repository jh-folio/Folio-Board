# Folio Board

**개인 투자자를 위한 로컬 우선 투자 리서치 워크스페이스**

[English README](README.md)

Folio Board는 내 PC에 저장한 시장 뉴스와 리서치 자료를 모아 일일 브리핑, 시장 맥락, 기업 분석, 근거 추적이 가능한 Deep Research로 정리해 주는 로컬 투자 리서치 도구입니다. 미국·한국·유럽·일본 네 시장을 다룹니다.

자료와 생성된 보고서는 기본적으로 내 컴퓨터에 저장됩니다. AI 기능은 선택 사항이며, 사용자가 설정한 로컬 CLI 연결을 통해 실행됩니다.

---

## 할 수 있는 일

- **모으기** — 미국·한국·유럽·일본 네 시장의 공개 RSS·뉴스를 원문 언어 그대로 수집하고, 직접 저장한 기사·리포트·공시를 `research-inbox/`에 넣습니다. 모은 자료 전체를 검색합니다.
- **하루와 한 주 읽기** — 네 시장 중 원하는 만큼 골라 일일 브리핑을 만들거나(시장마다 별도 보고서), 다음주 일정이 붙은 주간 요약을 만듭니다. 대시보드에서 직전 보고서 대비 실제로 달라진 것, 예정만이 아니라 발표된 결과까지 담은 시장 캘린더, 직접 고른 차트를 봅니다.
- **기업 분석하기** — 티커든 회사 이름이든 한글·일본어 표기든 적으면, 어느 기업으로 읽었는지 생성 전에 보여주고, 여러 곳이 맞으면 고르게 하며, 못 알아보면 그렇다고 말합니다.
- **질문에 답 찾기** — 딥 리서치에 투자 질문을 던지고 조사 계획을 먼저 확인·승인합니다. 보고서는 사용한 자료, 부족한 부분, Smart Collection 조사 범위, 그리고 내 생각을 각각 다른 층으로 보관합니다.
- **관심 대상 추적하기** — 워치리스트에 기업·섹터·테마를 담고 종목별 차트와 수집된 뉴스, 다음 실적 일정을 봅니다.
- **내 위치 확인하기** — 포트폴리오에 보유 종목을 입력하면 한 통화 기준 평가액, 시장·섹터·통화별 비중, 한 종목이 커진 정도를 봅니다. 지금 비중을 프리셋으로 저장해 얼마나 벌어졌는지 보고, 프리셋으로 과거 성과를 벤치마크와 비교하거나 프리셋 여러 개를 나란히 돌려 봅니다.
- **중기 흐름 따라가기** — 매일의 뉴스 아래를 흐르는 이야기를 정리한 Market Memory를 읽습니다. 근거가 뒷받침되면 시장별로 나눠 볼 수 있습니다.
- **내 생각을 따로 두기** — 보고서 옆에 메모를 적고, 얼마나 오래됐는지·반대 근거가 무엇인지·확인하겠다고 적은 것이 무엇인지 점검합니다. 내 메모는 내 생각으로 표시된 채 남고 보고서의 근거에 섞이지 않습니다.
- **AI를 쓰거나, 쓰지 않거나** — Home이나 도크에서 보유 종목·워치리스트 항목·보고서에 대해 Agent와 대화합니다. 대화는 내 컴퓨터에 저장돼 나중에 이어집니다. AI가 무슨 작업을 했는지는 작업 기록에 남고, 저장된 보고서를 고치자는 제안은 승인해야 반영됩니다. **AI 키가 없어도 동작합니다** — 자료 수집·검색·차트와 규칙 기반 보고서는 모두 로컬에서 만듭니다.
- **내보내기** — 생성한 보고서를 Obsidian이나 Notion으로 보냅니다.
- **자리 잡기** — 처음 실행하면 AI와 관심 시장을 정하는 짧은 안내가 뜨고, 어느 단계든 건너뛸 수 있습니다. 설정에서 AI CLI, 모델 선택, RSS, 자동화, 화면 테마(라이트·다크·시스템), 그리고 자료 저장 위치를 관리합니다 — 앱 폴더 밖으로 옮겨두면 업데이트할 때 손으로 복사하지 않아도 됩니다.

아직 포함하지 않은 기능:

- 자국 거래소에만 상장된 유럽·일본 기업의 분석. 공식 자료를 SEC에서 읽기 때문에, SEC에도 등록한 유럽·일본 기업(ASML·Shell·SAP·Toyota·Sony 등)은 미국 티커로 분석할 수 있습니다. 자국에만 상장된 기업은 아직 안 되며, 빈약한 보고서를 내는 대신 화면이 그렇게 말합니다. 자국 공시 경로는 다음 릴리즈에서 다룹니다
- 설치 프로그램/트레이 앱 수준의 마감 작업

저지연 뉴스는 검증된 근거가 아니라 초기 lead입니다. 이미 수집한 RSS 항목을 다시 읽어 표시할 뿐 추가 네트워크 호출·자격증명·별도 설정이 필요하지 않습니다. 페이지 스크래핑이나 유료 본문 우회를 하지 않습니다.

## 설치와 실행

자세한 설치 및 실행 방법은 [installation.md](installation.md)를 참고하세요.

권장 경로는 두 가지입니다.

- **AI Agent에게 맡기기**: GitHub 링크를 Codex, Claude Code 같은 로컬 코딩 Agent에게 주고 설치와 실행을 요청합니다.
- **직접 설치하기**: Python 의존성을 설치하고, `.env.example`을 `.env`로 복사한 뒤 시작 스크립트를 실행합니다.

설치 후 Windows 빠른 실행:

```text
start-archive.cmd
```

설치 후 macOS / Linux 빠른 실행:

```bash
bash start.sh
```

서버가 응답을 시작하면 브라우저가 자동으로 열립니다. 열리지 않으면 아래 주소로 직접 접속하세요.

```text
http://127.0.0.1:8787
```

Folio Board를 사용하는 동안 서버 창은 닫지 마세요. 닫으면 종료됩니다.

처음 실행하면 짧은 안내가 뜹니다. AI를 쓸지와 어느 시장을 볼지 두 가지만 묻고, 어느 단계든 건너뛸 수 있습니다. **AI 키가 없어도 동작합니다** — 자료 수집·검색·차트와 규칙 기반 보고서는 모두 로컬에서 만듭니다.

### 업데이트

새 버전은 버전 이름이 붙은 폴더로 풀리고, 그 폴더의 자료는 비어 있습니다. 예전 폴더에서 `data/`, `research-inbox/`, `config/`, `.env`를 복사해 넣고, 새 폴더가 잘 도는 것을 확인한 뒤 예전 폴더를 지우세요.

매번 복사하기 번거로우면 **설정 > 자료 위치**에서 자료를 문서 폴더로 옮겨두면 됩니다. 새 버전이 알아서 찾습니다. 옮기기는 복사만 하고 원본을 지우지 않습니다.

## 자료를 넣는 위치

사용자가 직접 제공하는 리서치 자료는 `research-inbox/` 아래에 넣습니다.

```text
research-inbox/
  articles/   # 저장한 기사, 웹페이지, 텍스트/마크다운/html 파일
  rss/        # RSS 수집 결과
  reports/    # 증권사 리포트, IR 자료, 리서치 PDF
  filings/    # SEC/DART 공시와 공식 문서
  links/      # URL 목록
```

Folio Board가 생성한 데이터는 `data/` 아래에 저장됩니다.

```text
data/
  briefings/
  company-analysis/
  topic-reports/
  investment-notes/
  caches and local databases
```

`data/`, `research-inbox/`, `config/`, `.env`는 로컬 설정과 생성물이 들어갈 수 있으므로 의도 없이 삭제하지 마세요.

## 주요 화면

### Home

Home은 AI Agent에게 투자 리서치를 요청하는 화면입니다. 입력창에 질문하거나 보고서 수정을 지시하고, 브리핑 생성·RSS 수집·기업 분석·딥 리서치는 빠른 실행 버튼으로 바로 시작할 수 있습니다.

아래쪽 Agent 작업 기록은 최근 상태만 한 줄로 보여주고, 펼치면 전체 기록을 확인할 수 있습니다. 작업 내용 원문이나 개인 자료는 표시하지 않습니다.

### Dashboard

화면 맨 위는 `무엇이 달라졌나`이고, 그 머리에 오늘의 이야기 비중이 있습니다. 그날 수집한 뉴스가 어떤 이야기로 나뉘는지 막대 하나로 보여주고, 이야기마다 기사 수·비중·직전 거래일 대비 변화를 함께 적습니다. 비중이 움직였다는 건 보도량이 움직였다는 뜻이지 이야기의 내용이 달라졌다는 뜻이 아니며, 화면에도 그렇게 적혀 있습니다.

그 아래 `무엇이 달라졌나`에는 최근 보고서를 만들 때 확인된 변화가 쌓입니다. 카드마다 새 정보·방향 전환·흐름 진전·보도량 이동 중 무엇인지, 한 줄 이유, 그리고 펼치면 직전과 현재를 나란히 놓은 비교와 근거 기사가 있습니다. 해당 보고서를 열거나, 비교 기준이 된 보고서를 열거나, Agent에게 물어볼 수 있습니다.

그 아래는 시장 캘린더입니다. 네 시장의 경제지표·중앙은행·휴장일·실적·공시·배당 일정을 모아 보여주고, 날짜의 출처에 따라 `확정`과 `예정`을 구분하며, 발표가 끝난 지표는 결과값까지 함께 적습니다. 마지막은 차트로, 외부 위젯이 아니라 Folio Board가 가진 데이터로 그립니다. 차트 종목 목록은 워치리스트와 별개이며 직접 추가·삭제·이동할 수 있고, 미국 20개·한국/유럽/일본 각 10개의 시가총액 상위 종목에서 시작합니다.

### Watchlist

관심 기업·섹터·테마를 로컬 워치리스트에 저장하고 관련 뉴스 카드와 시장 반응을 확인합니다. 기업을 이름으로 적으면 정식 명칭 하나로 저장돼서 같은 회사가 두 항목으로 갈리지 않고, 기업이 아닌 주제어는 적은 그대로 남습니다. 워치리스트 데이터는 로컬 워크스페이스에 남습니다.

종목 상세의 `내 Thesis`에서는 내 가설을 만들거나 수정하고, `최신 근거로 검토`를 눌러 최신 자료로 검토할 수 있습니다. 현재 사실과 내 Thesis, 최신 검토 결과, 근거와 반대 근거, 다음에 확인할 항목, 이전 검토 이력을 구분해 읽습니다. 화면을 열 때 AI가 실행되지는 않으며, `이 Thesis를 반박해줘`는 직접 눌렀을 때만 시작합니다. 이 대화는 저장된 판정을 자동으로 바꾸지 않습니다.

종목 카드와 상세에는 다음 실적 일정이 D-day와 함께 보입니다. 회사가 공식으로 알린 날짜가 아니라 제3자 예정치인 경우에는 그렇다고 표시하며, 그때는 회사 IR 공지로 다시 확인하는 것이 맞습니다.

### Portfolio

보유 종목을 직접 입력하면 한 통화 기준 평가액과 시장·섹터·통화별 비중을 봅니다. 화면은 `보유·평가`, `투자 리뷰`, `프리셋`, `백테스트` 넷으로 나뉩니다.

저장된 보유 현황을 먼저 보고, `보유 편집`을 눌러 수정한 뒤 저장하거나 취소합니다. 저장 전 변경은 평가나 대화의 기준에 섞이지 않습니다.

`투자 리뷰`는 입력 기준, 지난 리뷰 이후 변화, 우선 검토할 포지션, 공동 위험, 자료, 이력을 날짜별로 저장해 점검하는 곳입니다. `오늘 리뷰 갱신`, `검토 완료`, `이 리뷰의 가장 약한 전제를 찾아줘`는 서로 다른 버튼입니다. 검토 완료가 보유 종목·내 Thesis·저장된 확인 항목을 자동으로 바꾸지 않습니다. 이 화면은 내 판단을 점검하기 위한 것이며, 매수·매도·보유, 목표주가, 권장 비중 또는 포지션 크기 지침, 진입·청산·주문 지침을 제공하지 않습니다.

`프리셋`은 목표 비중을 저장해 두는 곳입니다. 지금 비중을 그대로 프리셋으로 만들 수 있고, 보유 종목이 목표에서 얼마나 벌어졌는지, 맞추려면 얼마를 사고팔아야 하는지 함께 봅니다. `백테스트`는 그 프리셋을 과거 가격에 돌려 벤치마크와 비교하고, 프리셋 여러 개를 나란히 놓고 볼 수도 있습니다. 백테스트는 리서치용이라 세금·수수료·체결오차·배당 처리에 한계가 있고, 결과는 저장 버튼을 눌렀을 때만 남습니다.

투자 리뷰는 투자 논리 미작성·최신 검토 미작성·검토 후 자료 부족을 구분합니다. 연결 자료는 저장된 보고서로, 이력은 선택한 날짜로 이동합니다. 기한 경과 수는 저장된 리뷰 범위이며 현재 전체 미완료 항목 수는 아닙니다.

### 선택 사항: Toss 증권 보유 내역 가져오기

Toss Open API 가져오기는 명시적으로 켠 로컬 읽기 전용 연동입니다. Portfolio에 보유 내역을 미리보고 확인해 반영할 수 있지만 주문을 내지 않습니다. Toss 증권 WTS에서 Open API 클라이언트를 등록하고 이 PC의 허용 IP를 설정한 뒤, **설정 > 연동 > API 연동**에서 `Toss Open API 사용`을 켜고 발급받은 Client ID와 Client Secret을 저장하세요. Secret은 운영체제 자격 증명 저장소에 보관되며 화면에는 마스킹된 상태만 표시됩니다. 수동 설정이 필요하면 `.env.example`의 opt-in과 기본 URL을 사용할 수 있지만 `.env`를 공유하면 안 됩니다.

설정 화면은 OAuth나 계좌 조회를 실행하지 않습니다. Portfolio에서 계좌 한 개를 고르고 미리보기를 확인한 뒤 명시적으로 확정해야 Portfolio가 바뀝니다. 실제 자격증명·계좌로 끝까지 검증하는 E2E는 아직 수행하지 않았습니다.

입력한 보유 종목은 로컬 워크스페이스에 저장됩니다.

### Briefing

미국·한국·유럽·일본 일일 시장 브리핑을 생성하고 읽습니다. 한 시장만 고르거나 여러 시장을 함께 고를 수 있고, 시장마다 별도 보고서로 저장되어 하나만 다시 만들거나 내보내거나 지워도 나머지는 그대로입니다. 브리핑은 뉴스/RSS 성격의 입력 자료와 가능한 경우 저장된 시장 스냅샷을 사용합니다. AI가 설정되어 있으면 더 풍부한 문장 생성에 활용하고, 사용할 수 없으면 규칙 기반 생성으로 대체됩니다.

시장마다 자기 세션 시계로 읽습니다. 한국 아침에 만든 브리핑은 밤사이 마감한 미국장과 같은 날 한국장을 함께 다루며, 어느 쪽이 어느 세션인지 밝힙니다.

일간 대신 **주간 요약**을 고를 수도 있습니다. 고른 날짜까지의 지난 7일을 정리하고, 다음주 일정(지표·중앙은행·실적·배당·휴장)을 확정된 것과 아직 예정치인 것을 구분해 함께 싣습니다. 그날 일간 브리핑과 따로 저장되어 서로를 덮어쓰지 않고, 목록에서 종류로 걸러 볼 수 있습니다.

### RSS Feed

네 시장의 공개 RSS/뉴스 항목을 수집, 필터링, 검색, 병합합니다. 유럽·일본 기사는 원문 언어 그대로 보관하고 시장·국가·언어를 함께 표시해서, 독일이나 일본 현지 보도를 그대로 읽거나 한 나라만 골라 볼 수 있습니다. Folio Board는 유료 기사 접근을 우회하지 않습니다. 공개 RSS/링크 메타데이터와 사용자가 직접 저장한 자료만 사용합니다.

무료로 공개된 기사 본문은 로컬 보관용으로 함께 저장할 수 있습니다. Settings > 자동화 > RSS 수집의 `기사 전문 저장` 옵션(기본 켜짐)으로 켜고 끌 수 있으며, 저장된 본문은 브리핑과 검색 품질을 높이는 데 사용됩니다.

### Market Memory

중기 시장 상황을 하나의 현재 상태와 소수의 핵심 드라이버로 요약합니다. “지금 어떤 시장인지, 왜 그런지, 다음에 무엇을 봐야 하는지”를 빠르게 이해하는 데 초점을 둡니다.

근거가 시장별로 따로 읽을 만큼 있으면 종합과 각 시장 탭이 나타납니다.

**거시 지도**에서는 미국 8개·한국 8개 지표의 출처, 단위, 추이와 수정 이력을 확인합니다. 미국의 과거 재현은 선택한 현지 날짜까지 제공된 FRED 보관판을 사용하며, 지원 시작일은 지표마다 다릅니다. 한국은 현재 수정치 추이와 로컬 수집 이후 확인한 변화를 제공합니다. 기존 FRED/BOK 키로 자료를 갱신할 수 있고, 하루 두 번 자동 갱신은 기본적으로 꺼져 있습니다.

### Company Analysis

공식 데이터와 로컬 리서치 자료를 활용해 기업 분석 보고서를 생성합니다. SEC ticker/CIK 조회, companyfacts, 10-K/20-F 공시 본문을 우선 사용합니다.

분석 대상은 떠오르는 대로 적으면 됩니다 — 티커, 회사 이름, 한글이나 일본어 표기 어느 쪽이든 좋습니다. 생성하기 전에 어느 기업으로 읽었는지 보여주고, 여러 곳이 맞으면 짧은 목록에서 고르게 하며, 아는 기업이 없으면 추측하지 않고 그렇게 말합니다.

**분석할 수 있는 범위.** 공식 자료는 SEC를 통해 읽습니다. SEC에도 등록한 유럽·일본 기업 — ASML·Shell·SAP·TotalEnergies·Toyota·Sony 등 — 은 미국 티커로 분석할 수 있습니다. 자국 거래소에만 상장된 기업은 아직 안 됩니다. 이때는 근거가 거의 없는 보고서를 만드는 대신, 어느 시장에 상장돼 있는지 알려주고 미국 티커가 있으면 그쪽으로 안내합니다. 한국 기업은 DART를 사용합니다.

### Deep Research

투자 질문을 입력하면 조사 계획과 지금 쓸 수 있는 자료를 먼저 보여줍니다. 확인하고 승인해야 생성이 시작됩니다.

계획은 기본적으로 AI가 씁니다. 질문에 맞는 분석 축과 검색어를 만드는 데 40초쯤 걸리고, 급할 때는 `규칙으로 빠르게`를 골라 즉시 받아볼 수 있습니다. 받은 계획이 마음에 안 들면 `계획 고치기`에 "밸류에이션 축은 빼고 공급 쪽을 자세히 봐줘"처럼 적으면 그 부분만 고쳐 다시 보여주고, `처음부터 다시`로 전부 새로 쓸 수도 있습니다.

`분석 조건 추가`에서 내 생각이나 관심 종목을 덧붙일 수 있습니다. 이 내용은 **가설로만 전달되며 외부 근거로 쓰이지 않습니다**. 저장한 자료 모음(Smart Collection)을 골라 조사 범위를 좁힐 수도 있는데, 이 역시 검색 규칙일 뿐 근거 자체는 아닙니다. 규칙은 `data/smart-collections.json`에 저장되고, 상세 화면에서 현재 몇 건이 일치하는지와 지난번 대비 무엇이 바뀌었는지 볼 수 있습니다. 화면을 열거나 새로고쳐도 AI가 저절로 실행되지는 않습니다.

보고서는 `data/topic-reports/`에 저장되며, 본문과 함께 승인한 계획·사용한 자료 목록·부족한 자료·품질 평가·그때의 시장 상태를 남깁니다. 보고서 안에서 근거와 내 생각은 항상 구분해서 보여줍니다.

AI를 쓸 수 없으면 규칙 기반으로 보고서를 만들고 그 사실을 표시합니다. 쓸 수 있는 외부 자료가 하나도 없을 때는 사용자가 직접 확인한 경우에만 생성하며, 근거가 부족하다는 점을 보고서에 명시합니다. 이미 저장된 보고서 본문은 **수정 제안을 승인해야만** 바뀝니다.

### Agent Work Log

AI가 무슨 작업을 했고 어떻게 끝났는지를 한 줄씩 보여줍니다. 무슨 작업인지, 지금 상태가 어떤지, 무엇이 저장됐는지만 표시합니다.

**작업 내용 원문은 저장하지 않습니다.** 질문한 문장, 대화 전문, 보고서 본문, 수정 내역, 첨부 파일, 로컬 경로, API Key, AI 도구의 원본 출력은 기록에 남지 않습니다.

### 리서치 인텔리전스 경계

브리핑·기업 분석·딥 리서치는 AI 설정이 없어도 규칙만으로 판단할 수 있는 것들을 보여줍니다. 내가 적어 둔 노트가 얼마나 오래됐는지, 최근 자료와 어긋나는 지점이 있는지, 확인하기로 한 항목의 기한이 됐는지 같은 것들입니다.

관심 종목을 기록해 두면 관련된 리서치 화면에 조용히 연결됩니다. 이때 보유 수량·가격·비중과 노트 본문은 보여주지 않습니다.

**이 자동 표시는 읽기 전용이고 보고서 본문을 바꾸지 않습니다.** AI가 실제로 무언가를 해석하는 것은 `최신 근거로 검토`, `Agent에게 변화 묻기`, `Agent로 위험 설명`처럼 사용자가 직접 눌렀을 때뿐입니다.

이 화면들은 매수·매도를 권하지 않습니다.

### Settings

화면 테마와 움직임, 관심 시장, AI Agent 모드, AI CLI 설정, 저장된 모델 선택, RSS/자동화, Obsidian, Notion 설정을 관리합니다.

**자료 위치**에서는 보고서와 수집 자료가 어디에 얼마나 저장돼 있는지 보고 그 폴더를 열 수 있습니다. 문서 폴더로 옮겨두면 새 버전이 복사 없이 알아서 찾습니다. 옮기기는 복사만 하고 원본을 지우지 않으니, 새 위치가 잘 보이는지 확인한 뒤에 예전 폴더를 지우세요.

**관심 시장**에서는 미국·한국·유럽·일본 중 수집하고 표시할 시장을 고릅니다(기본은 미국·한국). 여기서 끈 시장은 자료 수집이 멈추고 RSS 목록·브리핑 생성 선택지·시장 캘린더·시장 내러티브에서 함께 숨습니다. 유가·달러 같은 글로벌 자료는 항상 보입니다. 다시 켜면 그 시장 자료 수집이 바로 시작되지만, 꺼져 있던 기간의 기사는 피드가 아직 내어주는 범위까지만 들어옵니다.

### Obsidian

생성된 보고서를 로컬 Obsidian Vault로 내보낼 수 있습니다. Obsidian은 선택 사항이며, Folio Board를 사용하기 위해 필수는 아닙니다.

설정에서 `NOTION_TOKEN`, `NOTION_DB_ID`를 구성하면 생성된 보고서를 Notion 데이터베이스로 내보낼 수 있습니다. 토큰은 운영체제 자격 증명 저장소에 보관됩니다.

## 프라이버시

Folio Board는 로컬 우선으로 동작합니다.

- 원천 자료는 `research-inbox/`에 저장됩니다.
- 생성된 보고서, 노트, 데이터베이스, 캐시는 `data/`에 저장됩니다.
- 데이터 연동 키와 토큰은 운영체제 자격 증명 저장소에 보관되며, `.env`에는 비밀이 아닌 설정만 남습니다.
- 클라우드 저장은 필수가 아닙니다.

### 로컬 네트워크 안전

Folio Board를 공개 인터넷에 그대로 노출하지 마세요. LAN 보안을 충분히 이해하는 경우가 아니라면 호스트를 기본값 `127.0.0.1`로 둡니다. `FOLIO_HOST=0.0.0.0`으로 바꾸면 같은 네트워크의 다른 기기가 로컬 보고서, 설정, 노트, 포트폴리오 자료, 자동화 엔드포인트, Agent/CLI 조작에 접근할 수 있습니다.

`IMGBB_API_KEY`를 설정해 차트 이미지를 포함한 Notion 내보내기를 쓰면 차트 이미지가 외부 이미지 호스트로 업로드될 수 있습니다.

AI/LLM 기능을 켜면 선택된 보고서 맥락이나 요약된 근거 자료가 설정한 Provider 또는 CLI 도구로 전송될 수 있습니다. 로컬 규칙 기반 동작만 원하면 AI 기능을 끄면 됩니다.

이전 `.env`의 데이터 연동 비밀값은 자격 증명 저장소 이전이 성공한 뒤에만 제거됩니다. `.env`를 공유하거나 실제 API Key를 문서, 이슈, 채팅 로그에 붙여넣지 마세요.

## 문제 해결

브라우저가 자동으로 열리지 않으면 아래 주소로 직접 접속하세요.

```text
http://127.0.0.1:8787
```

의존성이 누락되었으면 아래 명령을 실행하세요.

```powershell
py -3 -m pip install -r requirements.txt
```

또는:

```bash
python3 -m pip install -r requirements.txt
```

AI 기능이 동작하지 않으면 다음을 확인하세요.

- Settings에서 AI Agent가 활성화되어 있는지
- 선택한 LLM CLI가 설치 및 인증되어 있는지
- Provider 설정을 바꾼 뒤 모델 목록을 새로고침했는지

AI를 쓸 수 없어도 Folio Board는 규칙 기반으로 계속 동작합니다. 문장이 덜 매끄러울 뿐 화면이 멈추지는 않습니다.

AI 생성은 설정한 CLI를 사용합니다. 이전 설정에 전환 안내가 표시되면 CLI를 선택해 저장하거나 AI를 꺼 주세요. 저장 보고서·과거 로그·외부 데이터 연동은 유지합니다.
