# 가격 시나리오

가격 시나리오는 외부 공시와 완결 거래일의 종가를 입력으로 삼는 규칙 계산이다.
개인 투자 이유·대화·사용자 가정을 정본의 근거로 쓰지 않는다.

현재는 입력 기반을 구현 중이며 화면/API·저장 장부와 기업분석 생성 경로에는 연결하지 않았다.
기존 기업분석의 한국 가격 조회는 같은 공식 거래소 규칙에 연결했다.
가격 시나리오 계산·화면은 아직 공개 동작에 연결하지 않았다.

- `history.py`: SEC 원자료의 기간별 태그 선택·최신 공시/이전 값·최대 10년,
  DART 당기/전기/전전기와 동일 연결 기준을 보존한다. 기존 보고서 요약을 바꾸지 않는다.
  DART 기말은 별도 원자료에서 확인한 `periodEnd`를 반드시 전달한다.
  보통주 배당은 `alotMatter`의 원/주 값을 읽고 우선주·결측·숫자 0을 구별한다.
- `securities.py`: SEC 표지의 정확한 ticker/context와 각주에서 상장증권 종류를 읽는다.
  20-F만으로 ADR을 판정하지 않고, ADS 비율·공시 주당 기준을 못 확인하면 제한한다.
- `support.py`: 공식 업종·상장증권 종류·통화·주식 단위 제한을 먼저 적용한다.
  종류 미확인에서는 기존 단위 함수의 compatible 결과로 주당 계산을 열지 않는다.
- `prices.py`: 미국/한국 종가 완결 시각과 진행 중 세션·stale을 확인한다.
  거래소는 공식 메타데이터로 정하고 한국 `.KS/.KQ` 순차 추정은 하지 않는다.
  `fetch_daily_history()`만 명시 조회를 수행한다. 11년 일봉의 `auto_adjust=False`
  종가와 공급자 사건을 수집하고 장중 가격·배당 조정 가격·기존 앱 캐시를 쓰지 않는다.
- `events.py`: 출처 간 사건을 한 번만 합치고 로그 거리로 가격 반영을 확인한다.
  공시 이후 사건만 주당 값/주식 수에 반영하고 검증된 ADS 비율을 마지막에 적용한다.
  한국 기말 주식 수는 `korean_shares.py`의 공식 단위 증명/기말 단위 잔차로 대조한다.
  spec-1의 두 단위 구간 계산은 `reconcile_korean_shares_v1`에 재현용으로 보존한다.
  빈 사건 목록만으로 `none_confirmed`를 반환하지 않는다.
- `sec_events.py`: 같은 기간의 희석 주식 수·EPS를 공시별로 짝짓고 모든 공시 짝을
  사건 배율의 곱과 대조한다. 일반 정정·누락·사건 출처 실패를 구별한다.
  공시 앞뒤의 예상 분할 흔적이 없으면 `unknown`이다. ADR의 공통주 흔적과 맞지 않는
  공급자 사건은 `ads_ratio_change`로 두되, 최신 20-F 이후 사건은 `unknown`이다.
- `dcf_history.py`: 같은 10년 이력에서 기존 DCF 독자가 읽는 연간 항목을 만든다.
  실제 기말·누락·0·공시 ID·주식 수 환산 출처를 보존하고 같은 FY의 모호한 값은 거부한다.
  이 어댑터 자체는 지원 여부를 확정하거나 DCF를 실행하지 않는다.
- `dart_events.py`: 무상증자 결정의 신주 배정비율에 1을 더하고 기준일 직전 거래일과
  예정 상장일을 구분한다. 연간 증감 공시의 날짜별 유상증자·전환·감자를 읽으며,
  미확인 종류·불완전 자료는 빈 목록으로 바꾸지 않는다. 예정일은 집행 확인과 다르다.
- `korean_shares.py`: spec-2의 이익소각/상환 누적 원값과 항목별 공식 단위 증명,
  사건 범위·당일 단위 순서를 보존한다. 같은 기말 단위로 환산해 잔차를 계산하며
  미확인 단위·상환 결측·정정/누적 감소는 unknown이다. DART의 `-`는 0이 아니다.
  원입력만 지문에 넣고 환산계수/잔차는 결과에 둔다. 이전 spec-1 결과는 바꾸지 않는다.
- `debt_inputs.py`: 확인된 연간 기말의 차입금·현금·개별 계정 출처를 묶는다.
  결측 부채를 0으로 채우지 않고 부분 포지션은 부분으로 표시한다. IFRS 차입금의
  유동성 부분 포함 여부는 공식 정의 근거가 있을 때만 사용한다.
- `dcf_runtime.py`: 조정된 주식 수·기준 가격·시가총액·FCF·성장 관측·금리·beta·
  세율·차입 비용·부채·말기 성장률을 포착하고 기존 10년 DCF 엔진으로 재현한다.
  지원 제한을 먼저 확인하고, 성장/할인율 대체값이면 안전마진 판정은 unknown이다.
- `decimal_ops.py`: 유한 Decimal 입력·원천 정밀도·정규 inputs SHA-256을 관리한다.

순수 입력 함수는 전달받은 원자료만 사용하며 캐시·개인 DB 쓰기를 하지 않는다.
실자료 확보·필드 해석과 입력 fixture 통과는 저장/보고서/UI 수용과 구분한다.

DCF 공통 성장률은 `company_analysis/dcf.py`가 실제 회계연도 간격을 사용한다.
같은 폴더의 `risk_free.py::risk_free_as_of()`는 기준 종가 날짜 이하 관측을
FRED→Yahoo→상수 순서로 선택하고 원관측 단위와 출처를 반환한다. 현재 장부/API에는
연결하지 않았으며 기존 최신 금리 조회/캐시와 별도다.

전체 입력 수용은 진행 중이다. 한국 사건 전체의 집행일·증감/소각 단위 대조와
실자료 원값 독립 검증, 실제 beta 확보, 입력 전부의 영구 저장/복구 및 공통 생성
경로 연결이 남아 있다. 입력 포착과 오프라인 재현을 제품 경로 연결로 간주하지 않는다.
누적 소각 단위가 분할 전후에 달라 현재 잔차로 설명되지 않는 사례는 `unknown`을
유지한다. 값을 임의 보정하거나 단위 검증 완료로 표시하지 않는다.
