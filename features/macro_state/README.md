# 거시 상태 계산

공식 거시 원장에서 선택한 입력으로 경기·물가·금융여건·위험을 계산하는 순수 함수입니다. 구현 중이며 API·화면·평가 도구에는 아직 연결하지 않았습니다. 결과는 예측이나 투자 지시가 아닙니다.

`rules.py`는 고정소수 경계, 관측기간 날짜, 결측과 3값 논리, 국면 신호 우선순위를 소유합니다. `inputs.py`는 정확한 관측 창·원천 무결성·사실 행·입력 지문을, `cycle.py`는 미국·한국 국면 조건을, `engine.py`는 네 축 출력을 조립합니다. 계산은 I/O나 이전 판정 상태 없이 동작합니다. 사용자 수용 전 모든 승격은 shadow이며, 평가 통과만으로 바꾸지 않습니다.

## 재현과 저장

- 계산 입력은 동일 cutoff에서 선택한 원장 행입니다. `rawValue`의 Decimal 문자열로 산술하며 미래 가용시각과 중복 선택을 거부합니다. 결측을 0이나 직전 판정으로 대체하지 않습니다.
- `observationSelection`은 최초 관측기간 선택을 기록합니다. 수정판 비교에서는 이 선택과 최초 공식 미발표 사실 집합을 전달해야 합니다. 최신 관측월·분기·일자·스프레드 날짜 집합을 새로 고르지 않습니다.
- `inputFingerprint`는 `macro-input-1`의 UTC 정규 시각, 정렬 원천 행, 결측 사유, 방법 버전·계산 옵션을 SHA-256으로 묶습니다. 기록 시각·승격 상태는 제외합니다. 국면 옵션이나 개발 진단 모드가 달라지면 같은 지문을 쓰지 않습니다.
- `store.py`의 `StateStore`는 기존 `market-memory.sqlite3`에 불변 스냅샷, 대체 관계, 사용자 승격 결정 테이블을 추가합니다. 동일 입력의 다른 결과는 오류입니다. 새 지문은 새 행이며 이전 스냅샷 ID는 계속 조회할 수 있습니다. 다른 지문을 저장할 때 사유가 필요합니다.
- migration 전에 SQLite backup API 사본을 만듭니다. 조회는 파일·테이블을 만들지 않습니다. 기존 스냅샷·대체 관계·승격 결정은 UPDATE/DELETE를 거부합니다.
- 승격은 명시적 사용자 확인과 평가 근거 참조가 필요하며 별도 결정의 projection으로 조회합니다. 한국 전 축과 미국 빠른 스트레스는 primary로 바꿀 수 없습니다. 개발 진단 결과는 스냅샷에 저장할 수 없습니다.
- `replay.py`는 읽기 전용 원장 판본 선택과 월말·금요일 cutoff를 제공합니다. 전체 평가 실행기·개발 조정·검증·최종 시험은 아직 연결하지 않았습니다.

현재 `nextCheckpoints`는 빈 목록이며 Calendar 연결은 후속 통합 작업입니다. API·화면 연결, 수정판 평가 일정과 평가 실행, 결과 독립 판독·승격 수용은 완료 조건으로 남아 있습니다.

검증: `py -3 -X utf8 -m pytest features/macro_state -q`. 표 형태 fixture로 경계값·목표표 전환·결측·상충을 검사합니다. 실제 자료 평가와 사용자 수용은 별도입니다.
