# 유형별 지침 — 거시 분석 (macro_analysis)

- 인과 경로를 가장 자세히 다뤄라: 정책금리 경로 → 실질금리 → 환율 → 자본흐름 → 위험선호가 어떻게 이어지는지 연결하라.
- 인플레이션과 정책 기대의 차이(시장이 가격에 반영한 경로 vs 중앙은행 커뮤니케이션)를 구분하라.
- 장단기 금리 구조(커브) 변화가 의미하는 바를 쉬운 말로 풀어라.
- 시나리오는 중앙은행 행동(인상/동결/인하) 조건으로 구성하라.
- 체크포인트에는 다음 FOMC/금통위/BOJ 일정과 확인할 지표 발표를 포함하라.

> 이 지침은 **무엇을 다룰지**만 정한다. 어느 섹션에 쓸지는 승인된 계획의 본문 섹션이 정한다.
> 여기 적힌 표현을 섹션 제목으로 만들지 마라.
